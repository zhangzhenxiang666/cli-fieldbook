**适用场景：** 减少工作目录展开的内容，或处理被忽略/过大的新文件。稀疏检出和是否跟踪文件是两个不同问题。

```sh
jj sparse list
jj sparse set --clear --add src --add Cargo.toml --add Cargo.lock
jj sparse list

# 恢复完整工作目录
# jj sparse reset

# 只有确认应进入版本历史时，才显式跟踪
# jj file track path/to/file
# jj file track --include-ignored path/to/large-or-ignored-file

# 若要停止跟踪，应先配置忽略规则，避免随后自动重新跟踪
# jj file untrack path/to/generated-file
```

**执行结果：** sparse 控制本工作区展开哪些路径，不等于从提交中删除其他目录。track 可以把特定新文件纳入快照；untrack 不等于普通删除文件。

**风险与边界：** file track 的实际解析器要求路径，不能仅输入裸命令。--include-ignored 还会绕过新文件大小限制。任何停止跟踪操作都不会清除旧历史中的密钥，泄密应另行撤销凭据与清理历史。
