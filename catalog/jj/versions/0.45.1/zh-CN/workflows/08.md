  - "command:"
  - command:rebase

**适用场景：** 下面三行是三种替代选择，不是一个应该连续执行的脚本。A、B、C 和 BASE 都需换成真实修订。

```sh
# A 及其全部后代一起移动
jj rebase -s CHANGE_A -o BASE

# 仅提取 A、C；未选中的后代接回原来的位置
# jj rebase -r 'CHANGE_A | CHANGE_C' -o BASE

# 只移动 B，插入到 A 前面
# jj rebase -r CHANGE_B -B CHANGE_A
```

**执行结果：** -s 用于“这一层开始的整段堆叠”，-r 用于“只移动指定集合”，-b 用于“从相对目标的分叉点搬分支”。-o 设父节点，-A/-B 则插入并重接相关边。

**风险与边界：** -b/-s/-r 互斥。-o 与 -A/-B 互斥；-A 与 -B 可组合以约束插入位置。重排有依赖的补丁可能产生冲突。v0.45.1 中 -d 仍是 --onto 的公开短别名。
