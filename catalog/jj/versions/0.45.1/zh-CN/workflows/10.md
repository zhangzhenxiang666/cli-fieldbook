title: 10. 合并分支并解决冲突

**适用场景：** feature-a 和 feature-b 是两个已有书签或可解析的修订。new 的多个父修订表示创建 merge change。

```sh
jj new feature-a feature-b -m "merge: integrate feature branches"
jj status
jj resolve --list

# 已配置 merge tool 时，让工具处理冲突
jj resolve

# 或手动编辑冲突文件，然后检查快照
jj status
jj diff
```

**执行结果：** 不需要进入 Git 那种必须立刻完成的全局 merge/rebase 中间状态。冲突可以存在于某个具体提交中，后续再编辑。

**风险与边界：** 默认 push 会防止发送不合适的冲突历史。--allow-conflicts 是放宽保护，不是解决冲突。工具只能帮助编辑，最终内容和测试仍由你确认。
