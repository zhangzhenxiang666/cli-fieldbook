**适用场景：** 仓库使用 Gerrit，review 是已配置远端，main 是实际评审目标分支。当前完成工作在 @-，而 @ 是新的空 change。

```sh
jj gerrit upload --remote review --remote-branch main -r @- --dry-run
# 先核对上传范围和服务端选项：
# jj gerrit upload --remote review --remote-branch main -r @-
```

**执行结果：** gerrit upload 负责 Gerrit 的评审上传语义，并支持 reviewer、cc、topic、label 等服务端选项；它不是所有托管服务通用的创建 PR 命令。

**风险与边界：** 这一命令的 -n 是 --dry-run；不要套到 git push 上。--submit、--skip-validation、隐私和通知选项有服务端权限/配置约束，客户端接受参数不代表服务端一定执行。
