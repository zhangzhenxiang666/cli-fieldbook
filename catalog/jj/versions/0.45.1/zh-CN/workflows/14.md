title: 14. 只撤销某个文件的修改：restore

**适用场景：** 当前 @ 是普通单父提交，想把一个文件恢复到父修订内容，而不是撤销整个 jj 操作。

```sh
jj diff -- src/config.rs
jj restore --from @- -- src/config.rs
jj diff -- src/config.rs

# 对指定 change 撤销其相对父树的修改，使用另一种模式：
# jj restore --changes-in CHANGE_A -- src/config.rs
```

**执行结果：** --from 指定来源，--into 指定被重写目标；未指定目标时通常作用于 @。--changes-in 用合并父树作为基线，因此更适合表达“撤销这个 change 的改动”。

**风险与边界：** restore 会覆盖目标路径的修改。这里没有正常可用的 restore -r；v0.45.1 的隐藏 -r 仅用于报错提示。误操作后先检查 op log，不要立刻 gc。
