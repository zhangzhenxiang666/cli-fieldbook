---
title: 20. 批量验证堆叠中的每个提交：run
uses:
  - "command:"
  - command:run
---

**适用场景：** Rust 项目希望检查主线到当前工作的每一层，而不是只验证最终合并结果。显式限定 revset，并避免测试产物改写提交。

```sh
jj run -r 'trunk()..@' --root --ignore-changes -- cargo test

# 资源足够、测试彼此独立时，再选择并发：
# jj run -r 'trunk()..@' --root --ignore-changes --jobs 4 -- cargo test
```

**执行结果：** run 在隔离工作副本中执行命令；--root 从项目根运行；--ignore-changes 忽略测试造成的工作树变化，并允许检查不可变提交。

**风险与边界：** 隔离目录不是安全沙箱。外部命令可联网、访问数据库或修改目录外文件。复用目录会保留构建产物，必要时 --clean。CI 不应轻易加 --ignore-errors，因为失败不会按通常方式决定最终退出码。

源码依据：[jj run](https://github.com/jj-vcs/jj/blob/7c41cdeb16b6b321c64e789a966b6adf723816a5/cli/src/commands/run.rs)。
