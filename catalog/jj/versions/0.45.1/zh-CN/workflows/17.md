title: 17. 追踪一个 change 怎样被改写：evolog 与 interdiff
uses:
  - "command:"
  - command:evolog
  - command:interdiff
---

**适用场景：** 提交图只能展示当前关系，无法直接说明同一个 change 被你 amend、rebase、squash 后怎样演化。

```sh
jj evolog -r @
jj evolog -r @ -p

# OLD_COMMIT 和 NEW_COMMIT 必须是两个具体版本的 commit ID
# jj interdiff --from OLD_COMMIT --to NEW_COMMIT
```

**执行结果：** log 查看提交关系，evolog 查看 change 的演化，op log 查看仓库操作。interdiff 比较两个版本的改动，并处理父基线差异。

**风险与边界：** 要比较旧对象，优先用具体 commit ID；当前 change ID 往往指向最新可见版本。不要把 evolog 当成作者/时间排序的普通日志。
