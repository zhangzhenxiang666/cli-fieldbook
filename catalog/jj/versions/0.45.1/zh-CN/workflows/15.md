---
title: 15. 操作做错了：undo、redo 与操作日志恢复
uses:
  - "command:"
  - command:redo
  - command:undo
---

**适用场景：** 适用于误 rebase、abandon、squash、移动书签等仓库操作。先看操作日志，区分回退到某个状态和只反做某次操作。

```sh
jj op log -n 10

# 刚才那一步做错了
jj undo

# 反悔，重做刚撤销的一步
jj redo

# 更精确地处理：以下是替代方案，先把 OP_ID 换成实际操作 ID
# jj op show OP_ID
# jj op restore OP_ID
# jj op revert OP_ID
```

**执行结果：** restore 恢复到指定操作后的仓库视图；revert 在当前视图上反向应用某次操作，尽量保留别的后续工作。undo/redo 负责最近操作的前后移动。

**风险与边界：** 操作 ID 不是 change ID/commit ID。v0.45.1 的 jj undo 不接受操作 ID。任何本地恢复都不会自动撤回已经发生的远端 push，或恢复未跟踪的外部文件。
