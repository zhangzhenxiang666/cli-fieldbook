公开命令的参数表按官方完整 CLI reference 整理，源码复核包括命令树、全局参数、
差异格式参数、默认配置及重点命令的隐藏参数和行为；debug / bench 根据固定版本源码补充。
这不是逐个文件执行自动 AST 审计的报告，也不声称枚举了所有未文档化的兼容参数。
“Hidden / Compatibility Options” 收录的是已核实项目，且区分可用别名、无操作兼容项和报错入口。

保留 `Usage:`、`Commands:`、`Arguments:`、`Options:`、`Diff Formatting Options:`、
`Global Options:` 的 help 结构，命令、参数、占位符不翻译，说明用中文重述。
这不是本环境运行 `jj --help` 后生成的逐字终端转录：中文排版、换行和补充注释经过重排，
部分冗长英文说明合并为中文要点；不保留 ANSI 颜色或终端的逐字节布局。

未在本环境安装/编译 jj，也未在实际仓库逐条执行工作流。源码通过在线官方源文件查阅；
无法建立本地源码克隆，因此不附带“已验证的源码快照”。
遇到帮助文字与解析器/实现不一致的地方，明确列在 `sources-and-coverage.md`。
你的二进制版本、编译 feature、操作系统和个人配置仍可能改变可用性和默认行为。

本手册的 CLI“参数”指命令行位置参数与选项；Revset 已在本次补篇中提供完整语言参考，覆盖 54 个文档函数、1 个弃用兼容名和 8 个默认别名。
TOML 的全部配置键、template 方法和外部工具参数仍不在“完整 CLI 参数”的范围内；Fileset 这里只解释 Revset 涉及的路径参数。

**Revset 补充修订：** 新增完整函数/符号/模式/别名、日志标记及 20 个查询场景；纠正旧 `all:` 建议。独立文件见 [revsets-zh.md](../reference/revset/index.md)。
