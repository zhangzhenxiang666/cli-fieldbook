```bash
herdr --session review
```

在另一个终端查询同一个会话：

```bash
herdr --session review workspace list
herdr session list --json
herdr session attach review
```

默认会话 `default` 与 `review` 分开。下面是有破坏性的清理，不是退出界面的步骤：

```bash
# 仅在确认该会话任务不再需要运行时执行：
herdr session stop review --json
# 仅在还确认不需要保留布局/会话状态时执行：
herdr session delete review --json
```
