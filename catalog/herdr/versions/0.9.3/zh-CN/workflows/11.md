```bash
if ! herdr agent prompt reviewer \
  "只检查当前代码并给出问题清单，不修改文件。" \
  --wait --timeout 120000; then
  printf '%s\n' "提交/等待未成功；先检查状态，不自动重试。"
fi

herdr agent get reviewer
herdr agent read reviewer --source recent-unwrapped --lines 160
```

即使命令成功，也要判断返回的是 idle、done 还是 blocked。`blocked` 可能在等你授权，并不是审查完成。

显式限制等待目标时：

```bash
herdr agent wait reviewer \
  --until idle --until done --timeout 120000
```

这仍然是状态等待；不是“自动跳过 blocked”。目标持续 blocked 时可能等到超时，必须读屏处理。
