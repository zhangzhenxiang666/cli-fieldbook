把下面路径与 ID 替换成自己已审核的插件：

```bash
herdr plugin link "/absolute/path/to/my-plugin" --disabled
herdr plugin list --json
herdr plugin config-dir my-plugin
```

先读插件 manifest、入口脚本及配置。`config-dir` 会确保相关用户目录存在，不能视为完全无副作用的路径查询。

确认后：

```bash
herdr plugin enable my-plugin
herdr plugin action list --plugin my-plugin
```

只调用真实列出的动作；例如你确有 `refresh`：

```bash
herdr plugin action invoke refresh --plugin my-plugin
herdr plugin log list --plugin my-plugin --limit 50
```

`my-plugin` / `refresh` 是模板占位，不声称这是上游内置插件。不要安装未知来源时默认加 `--yes`。
