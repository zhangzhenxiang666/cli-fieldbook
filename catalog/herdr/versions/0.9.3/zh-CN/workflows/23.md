前提：已有启用的插件及真实 entrypoint。将 `my-plugin`、`dashboard` 换成插件中实际存在的 ID。

```bash
herdr plugin pane open \
  --plugin my-plugin \
  --entrypoint dashboard \
  --placement popup \
  --width 80% --height 70% \
  --workspace "$workspace_id" \
  --no-focus
```

这些 popup/尺寸参数来自 v0.9.3 实际解析器，不是从该版本 spec 的枚举里推出来的。可能不会出现在补全中。

`plugin pane open` 默认会聚焦，因此示例显式写 `--no-focus`。拿到真实 plugin pane ID 后才执行：

```bash
herdr plugin pane focus "$plugin_pane_id"
# 不再使用这个插件窗格时：
herdr plugin pane close "$plugin_pane_id"
```

不要把目标 workspace 的 ID 当成插件 pane ID。
