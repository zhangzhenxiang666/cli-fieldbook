---

把 `build-host` 替换为你的 SSH 配置别名：

```bash
herdr --remote build-host
```

选择远程按键策略：

```bash
herdr --remote build-host --remote-keybindings local
# 或明确使用 server 配置：
herdr --remote build-host --remote-keybindings server
```

这是远程 TUI 启动，不写成 `herdr --remote build-host pane list`。远程安装/升级提示中涉及重启或重置时，应确认远程正在运行的任务是否可以受影响。不要为了消除版本警告直接批准破坏性重置。
