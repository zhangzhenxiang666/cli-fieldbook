```bash
herdr machine add build-host --label builder --remote-session review
herdr machine list --json
herdr machine status builder --json
```

连接准备可能安装或升级远程 Herdr，以交互提示为准。然后所有远程 API 调用显式带相同前缀：

```bash
herdr --machine builder status server --json
herdr --machine builder workspace list
herdr --machine builder agent list
```

创建远程工作区：

```bash
herdr --machine builder workspace create \
  --cwd "/remote/absolute/project" --label "remote-review" --no-focus
```

返回的 ID 属于远程目标，不要去掉 `--machine builder` 后继续操作。也不要再加本地 `--session`。连接失败后先检查状态；写请求可能已经执行，不应盲目自动重放。
