只用于你能控制命令内容、且 pane 已停在 shell 的场景。下面以 Rust 项目的 `cargo check` 为例；Python 命令使用 `uv run`。

```bash
marker="HERDR_DONE_$(uv run --no-project python -c \
  'import uuid; print(uuid.uuid4().hex)')"

herdr pane run "$pane_id" \
  "cargo check; rc=\$?; printf '\n%s:%s\n' '$marker' \"\$rc\"" \
  || exit 1

herdr pane wait-output "$pane_id" \
  --regex "^${marker}:[0-9]+$" \
  --source recent-unwrapped --lines 200 --timeout 120000

herdr pane read "$pane_id" --source recent-unwrapped --lines 200
```

正则锚定整行，避免命令回显包含 marker 时提前命中。不同运行使用不同 marker，避免旧日志误匹配。最后一行的 `:0` 才表示所包装命令成功；其他数字是失败退出码。等待超时只是尚未观察到标记，不应立即重复提交原任务。

这个模式不是 Herdr 原生进程 exit-code API，也不能消除历史被截断、终端关闭等情况。
