---
title: 07. 分别读当前屏幕、近期日志和检测视图
uses:
  - "command:"
  - command:pane
  - command:pane/read
---

```bash
herdr pane read "$pane_id" --source visible
herdr pane read "$pane_id" --source recent-unwrapped --lines 120
herdr pane read "$pane_id" --source detection
```

看确认框用 visible；看长日志用 recent-unwrapped；检查状态识别依据用 detection。需要保留颜色/控制序列的导出可显式选择 ANSI：

```bash
herdr pane read "$pane_id" --source recent --ansi > pane-ansi.txt
```

这些命令直接输出文本，不应统一接 `.result` 的 jq 过滤器。ANSI 文件包含控制序列，展示、转发前注意终端安全。
