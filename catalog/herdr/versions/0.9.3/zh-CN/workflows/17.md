只读流：

```bash
herdr terminal session observe "$pane_id" > terminal-events.ndjson
```

这是持续运行的 NDJSON 流，可由调用端中断观察；不要把文件当作普通屏幕文本。流中帧数据需按 schema 解码。若只要当前输出，`pane read` 更简单。

直接交互附着：

```bash
herdr agent attach reviewer
```

需要接管时才加 `--takeover`，这可能影响现有写入控制者。退出附着按 Ctrl+B 然后 q，而不是在 Agent 里发送终止进程的按键。`terminal session control` 面向协议集成，应先阅读 `api schema`，不要往它的 stdin 直接粘贴 shell 命令。
