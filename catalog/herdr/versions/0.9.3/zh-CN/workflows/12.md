---
title: 12. Agent blocked 时先看屏幕，不盲目补发 prompt
uses:
  - "command:"
  - command:agent
  - command:agent/get
  - command:agent/read
  - command:agent/send-keys
---

```bash
herdr agent get reviewer
herdr agent read reviewer --source visible
```

先确认它究竟在问什么。人工决定需要的回复或键盘操作，再发对应输入。例如确认要退出当前界面的场景才发送 Escape：

```bash
# 仅当你已读屏并确认 Escape 是所需操作：
herdr agent send-keys reviewer esc
```

不要在未知确认框里自动发送 enter、y 或授权选项。已经 blocked 的 Agent 会在 prompt 提交前报 `agent_blocked`；`release-agent` 也不是解决确认框的命令，它释放的是 hook 状态报告权威。
