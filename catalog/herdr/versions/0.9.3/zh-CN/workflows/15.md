```bash
herdr integration status
herdr integration status --outdated-only
```

确认使用的 Agent 和改动范围后，针对具体目标安装/更新：

```bash
# 将修改 Codex 的相关集成配置。
herdr integration install codex
herdr integration status
```

要移除时使用对应目标的 `integration uninstall`。没有通用的 `install all`。

Antigravity 的 KIND / TARGET 不同：启动种类使用 `agy`，集成安装使用 `antigravity-cli`。`letta` 在该版本仍标为实验性。
