```bash
herdr workspace rename "$workspace_id" "API review"
herdr pane rename "$pane_id" "review console"
herdr agent rename reviewer "api-reviewer"
herdr terminal title set "Review session"
```

这四个名称属于不同层级。纯展示状态可以通过元数据报告：

```bash
herdr workspace report-metadata "$workspace_id" \
  --source my-review-script --token phase=review --ttl-ms 60000

herdr pane report-metadata "$pane_id" \
  --source my-review-script --title "正在审查" \
  --token stage=analysis --ttl-ms 60000
```

token 只有被相应 UI 配置引用才会显示。引用字面 `$stage` 时注意 shell 引号。清理时：

```bash
herdr pane report-metadata "$pane_id" \
  --source my-review-script --clear-title --clear-token stage
herdr terminal title clear
```

不要使用 `report-agent --state done` 伪造完成：该状态值根本不在这条命令的允许集合中。
