```bash
herdr tab create --workspace "$workspace_id" \
  --cwd "$PROJECT" --label "tests" --no-focus

herdr pane split --pane "$pane_id" \
  --direction right --cwd "$PROJECT" --no-focus

herdr tab list --workspace "$workspace_id"
herdr pane list --workspace "$workspace_id"
```

保存新返回对象中的真实 ID。不要假定 split 后新 pane 的 ID 是旧 ID 加一。`right` 是向右新增窗格，`down` 是向下；`pane split` 实际要求方向，即使某些帮助展示没有将其标成必需。

要从某个起点向右导航，才使用：

```bash
herdr pane focus --pane "$pane_id" --direction right
```
