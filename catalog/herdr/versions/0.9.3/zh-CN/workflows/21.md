---
title: 21. 继续用 jj 管版本，让 Herdr 只管理终端
uses:

---

Herdr 的 `worktree` 子命令不会变成 `jj workspace`。对于已经准备好的 jj 工作目录，直接创建普通 Herdr workspace：

```bash
JJ_DIR="/absolute/path/to/existing-jj-workspace"
herdr workspace create --cwd "$JJ_DIR" --label "jj-review" --no-focus
```

进入该目录的终端后，版本控制仍由你熟悉的 jj 工作流完成。Herdr 负责终端布局、Agent 启停交互和可观察性，不接管 revision 管理。

多个 Herdr workspace 指向同一个 jj 工作目录也不等于独立 working copy。需要并行写代码时，先按你安装的 jj 版本建立并检查独立 workspace，再将各目录传给 Herdr；不要用 Git worktree 命令代替 jj 的隔离设计。
