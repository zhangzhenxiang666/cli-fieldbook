先确认该 pane 当前停在 shell 提示符：

```bash
herdr pane process-info --pane "$pane_id"
herdr pane read "$pane_id" --source visible
```

分两次输入：

```bash
herdr pane send-text "$pane_id" "pwd"
herdr pane send-keys "$pane_id" enter
```

或者一次提交：

```bash
herdr pane run "$pane_id" "pwd"
```

二者都是向真实终端发送输入。若当前是 Agent 或编辑器界面，输入会进入那个程序。`pane run` 返回 0 不代表 `pwd` 或后续命令的退出码为 0。
