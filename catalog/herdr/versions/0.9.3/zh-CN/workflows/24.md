schema 是当前二进制内置文档：

```bash
herdr api schema
herdr api schema --output herdr-api.schema.json
```

不要把 `--output` 与 `--json` 一起使用。实时状态则来自 server：

```bash
if herdr api snapshot > snapshot.json 2> snapshot-error.txt; then
  jq . snapshot.json
else
  cat snapshot-error.txt >&2
fi
```

接入程序应明确：请求目标机器与 session、对象 ID、超时、退出码、返回类型、是否可以重试。`pane run` / `agent prompt` 属于有副作用的输入提交；连接失败或等待超时后，先查询状态再决定重试。

长期维护这份中文手册时，先运行包内 `audit-help.py` 在已安装的 0.9.3 上导出本机原始帮助。升级到新版本后应重新对照源码；不要静默沿用所有历史别名、默认值和隐藏参数。
