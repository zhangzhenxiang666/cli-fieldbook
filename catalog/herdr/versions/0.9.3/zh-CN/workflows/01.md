```bash
herdr --version
herdr
```

进入 TUI 后创建/使用窗格。需要暂时离开时，按 **Ctrl+B，然后 q**；之后再次执行 `herdr` 返回。不要为了离开界面运行 `server stop`，否则会影响托管进程。

在另一个 shell 查看状态：

```bash
herdr status
herdr workspace list
herdr agent list
```

本手册绑定 0.9.3；版本不同先核对本机帮助。
