前提：目标环境中已安装并配置好 `codex`；本工作流不替你安装或登录它。

```bash
herdr pane process-info --pane "$pane_id"
herdr pane read "$pane_id" --source visible

herdr agent start reviewer --kind codex \
  --pane "$pane_id" --timeout 60000

herdr agent get reviewer
herdr agent read reviewer --source visible
```

`agent start` 成功表示已在同一终端检测到预期 Agent，且能够交互。不是只把命令名写进了终端。若需要传 Agent 自己的参数，应放到 `--` 后，并按你安装的 Agent 版本确认其支持的参数。
