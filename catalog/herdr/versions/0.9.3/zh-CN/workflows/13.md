分别创建两个工作区，保存每个返回的 root pane ID。最简单是重复工作流 05，将 label 改为 `review-a`、`review-b`，分别保存为 `pane_a`、`pane_b`。

```bash
herdr agent start reviewer-a --kind codex --pane "$pane_a"
herdr agent start reviewer-b --kind codex --pane "$pane_b"

herdr agent prompt reviewer-a "只审查错误处理，不修改文件。"
herdr agent prompt reviewer-b "只审查并发与资源释放，不修改文件。"

herdr agent wait reviewer-a --timeout 120000
herdr agent wait reviewer-b --timeout 120000

herdr agent read reviewer-a --source recent-unwrapped --lines 160
herdr agent read reviewer-b --source recent-unwrapped --lines 160
```

这里两个 prompt 先后快速提交，工作可以并行，随后逐个等待。不要用随用户焦点变化的“当前 pane”指挥多个 Agent。若两者要修改代码，应先隔离 checkout / jj workspace 或明确协调策略；两个 Herdr 工作区指向同一目录并不提供文件隔离。
