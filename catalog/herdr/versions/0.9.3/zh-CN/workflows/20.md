这是 **Git 仓库** 的 workflow，不是 jj 的 workspace 管理。先列出现状：

```bash
herdr worktree list --cwd "$PROJECT"
```

需要隔离的 Git 分支 checkout 时：

```bash
herdr worktree create --cwd "$PROJECT" \
  --branch feature/herdr-review --label "isolated-review" --no-focus
```

现有 worktree 可按真实路径重新打开：

```bash
herdr worktree open --cwd "$PROJECT" \
  --path "/absolute/path/to/existing-worktree" --no-focus
```

只是关闭 Herdr 工作区用 `workspace close`。确实要删除 checkout、且已检查并保存所有改动时，才对对应 Herdr workspace ID 执行：

```bash
# 此命令删除 checkout；先确认 ID 及未提交内容。
herdr worktree remove --workspace "$worktree_workspace_id"
```

不要把 `--force` 当成默认参数。`--trust-repository` 也只对已审核的仓库显式使用。
