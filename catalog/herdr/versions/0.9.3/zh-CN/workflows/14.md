在线解释：

```bash
herdr agent explain reviewer --verbose
herdr agent explain reviewer --json > detection-explain.json
herdr pane read "$pane_id" --source detection > detection-screen.txt
```

离线复现（样本应清除密钥、私人路径或敏感输出）：

```bash
herdr agent explain --file detection-screen.txt \
  --agent codex --verbose
```

查看规则版本，再按需更新：

```bash
herdr server agent-manifests --json
# 下面会获取并重载检测规则。
herdr server update-agent-manifests --json
```

更新检测 manifest 不会升级 codex 可执行程序，也不保证所有问题来自识别规则。
