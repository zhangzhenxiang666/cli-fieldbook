先导出当前二进制内置默认值作参考，不直接覆盖现有配置：

```bash
herdr --default-config > herdr-default.toml
herdr config check
```

手动修复配置后重载：

```bash
herdr server reload-config
```

只有确实要放弃自定义键位时使用：

```bash
# 会修改配置并自动留下键位重置备份。
herdr config reset-keys
herdr server reload-config
```

不要在尚未理解现有定制时把 `herdr-default.toml` 整份复制覆盖到个人配置。
