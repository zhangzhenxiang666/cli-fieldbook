---
title: 9. SSH 的两条路径与允许路由的命令
---

`herdr --remote SSH_TARGET` 是远程 **TUI 附着**。`herdr --machine LABEL_OR_ID ...` 是对已保存机器的 **API 路由**。在 TUI 里选中远程机器，不会让另一个本地 shell 发出的 `herdr pane ...` 自动变成远程命令。

`--machine` 解析 ID 优先；名称必须唯一且大小写精确匹配，配置必须处于启用状态。SSH 别名不自动等同于 Herdr label。它使用保存配置的会话，不能与 `--session`、`--remote` 等启动选项组合。不存在“远程失败后自动落到本机继续执行”的安全承诺；写请求也不应在连接错误后盲目重放。[S10](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/target.rs#L174-L301)

v0.9.3 的路由白名单：

| 分类         | 可路由命令                                                     |
| ---------- | --------------------------------------------------------- |
| 对象 API     | workspace、worktree、tab、pane、notification                  |
| Agent      | 除 `attach` 和 `explain --file` 外的 Agent API 命令             |
| 快照/状态      | `api snapshot`、`status server`                            |
| 插件 API     | link、unlink、enable、disable、list、action、log/logs、pane      |
| Server API | stop、reload-config、agent-manifests、reload-agent-manifests |

本地 update、config、machine 管理、session 管理、integration 安装、plugin install/uninstall/config-dir、api schema，以及 terminal 附着/流，不在这个白名单。`server update-agent-manifests` 也不在其中。所有路径参数均应以**实际执行机器**的文件系统为准。\[S10，特别是 `validate_machine_command`]
