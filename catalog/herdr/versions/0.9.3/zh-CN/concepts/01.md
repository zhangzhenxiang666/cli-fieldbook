---
title: 1. 先分清这六层
---

```text
machine（本机或保存的 SSH 机器）
└── session / server（一个命名运行会话）
    └── workspace（项目或任务工作区）
        └── tab（标签页）
            └── pane（布局中的窗格）
                └── terminal / PTY（真实终端及其进程）
                    └── Agent（被检测到的交互式编程助手）
```

这是理解 CLI 对象关系的示意，不是数据库结构图。工作区、标签页、窗格、底层终端和 Agent 的 ID 不可随意互换。API 返回的 ID 应视为**不透明字符串**，保留原值；不要自行拼接 `w1:p1`，也不要把 UI 的第一个标签页当作 `tab_id=1`。

显示名称用于可读性，ID 用于稳定定位。Agent 命令中允许的 TARGET 解析与严格的 workspace/tab ID 参数不同。机器配置中的 `PROFILE_ID`、`LABEL_OR_ID`、`SSH_TARGET` 也有不同含义。自动化应创建/列举对象、保存返回的 ID，再对这些 ID 操作。

默认会话名称是 `default`。`HERDR_SESSION` 和根级 `--session NAME` 用于会话选择。`--machine` 则使用保存的机器配置中绑定的远程会话，不能再混入其他启动选项。[S02](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/main.rs)[S03](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli.rs)[S10](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/target.rs#L174-L301)
