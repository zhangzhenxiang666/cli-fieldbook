---
title: 7. 三种输入方式及其完成边界
---

| 命令                                   | 发送什么                 | 返回成功能证明什么           |
| ------------------------------------ | -------------------- | ------------------- |
| `pane send-text`                     | 字面文本，无 Enter         | 输入请求被接受             |
| `pane send-keys` / `agent send-keys` | 键盘事件序列               | 按键请求被接受             |
| `pane run`                           | 文本 + Enter 的一次提交     | 命令被提交，不是进程退出成功      |
| `agent prompt`                       | 面向 Agent 的 prompt 提交 | 以该命令返回语义为准；不等于任务已完成 |
| `agent prompt --wait`                | 提交并等待状态              | 某个状态条件被满足，仍需核验任务结果  |

`pane run` 不是 `exec` 返回退出码的远程调用接口。要可靠判断自己控制的 shell 任务，输出本次运行唯一的结束标记并带退出码，再用 `wait-output` 匹配。匹配应锚定完整一行，避免 shell 回显中的标记误命中。

按键名中 `esc` 是规范 Escape 名称，`escape` 仍被接受。组合键如 `ctrl+c`；支持的常见修饰符包含 ctrl/control、alt、shift、cmd、super，实际效果仍取决于终端/平台。不要把 `ctrl+c` 当作三个可见字符输入。[S03](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli.rs)[S04](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/pane.rs)[S05](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/agent.rs)
