---
title: 8. CLI 输出分类与错误处理
---

| 类别             | 代表命令                                                                           | 脚本处理方式                 |
| -------------- | ------------------------------------------------------------------------------ | ---------------------- |
| API JSON 响应    | workspace/tab/pane 查询与创建、agent 查询等                                             | 按具体 schema 读取 `result` |
| 默认人类文本，可选 JSON | status、machine list/status、session list/stop/delete、plugin list                | 需要结构化读取时显式 `--json`    |
| 直接文本 / ANSI    | pane read、agent read                                                           | 保存或按文本处理，不直接假设 JSON    |
| 成功通常无正文        | pane send-text/send-keys/run/report-\*、release-agent、workspace report-metadata | 首先检查退出码                |
| 持续 NDJSON 流    | terminal session control/observe                                               | 逐行解码，处理持续流与关闭事件        |
| 本地文件/脚本文本      | completion、--default-config、--skill、config-dir                                 | 按对应文件格式保存              |

通用 API 响应常见形式为 `{ "id": ..., "result": ... }`，API 错误写入 stderr，常见形态为 `{ "id": ..., "error": { "code": ..., "message": ... } }`。但参数错误、本地工具错误等也可能是普通文本 stderr；**不是所有 stderr 都能直接交给 JSON parser**。

常用退出约定：成功 0；运行/API 失败通常 1；使用方式错误通常 2。`config check` 发现问题也返回 1。不要把所有非零都解释成“目标对象不存在”。

`api schema --json` 输出 schema；`api schema --output PATH` 写文件；两者互斥。`agent explain --json` 输出解释对象，不是固定的 API 响应外层。自动化应为正在调用的命令确定契约，而不是给整个 CLI 写一个盲目的 `.result` 解包器。[S03](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli.rs)[S04](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/pane.rs)[S05](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/agent.rs)[S14](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/api.rs)[S15](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/runtime.rs)[S16](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/status.rs)
