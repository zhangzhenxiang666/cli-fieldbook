---
title: 11. 常用默认快捷键
---

默认前缀是 **Ctrl+B**。表中的 `前缀 → x` 表示先按 Ctrl+B，再按 x，不是一直按住所有键。自定义配置可能覆盖这些默认值。[S02](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/main.rs)

| 动作              | 默认键                        |
| --------------- | -------------------------- |
| 显示帮助            | 前缀 → `?`                   |
| 打开设置            | 前缀 → `s`                   |
| 脱离客户端           | 前缀 → `q`                   |
| 重载配置            | 前缀 → `Shift+R`             |
| 打开通知目标          | 前缀 → `o`                   |
| 工作区选择器          | 前缀 → `w`                   |
| 跳转              | 前缀 → `g`                   |
| 新建工作区           | 前缀 → `Shift+N`             |
| 新建 Git worktree | 前缀 → `Shift+G`             |
| 重命名工作区          | 前缀 → `Shift+W`             |
| 关闭工作区           | 前缀 → `Shift+D`             |
| 新建标签页           | 前缀 → `c`                   |
| 重命名标签页          | 前缀 → `Shift+T`             |
| 上/下一个标签页        | 前缀 → `p` / `n`             |
| 标签页 1..9        | 前缀 → `1`..`9`              |
| 关闭标签页           | 前缀 → `Shift+X`             |
| 重命名窗格           | 前缀 → `Shift+P`             |
| 编辑滚动历史          | 前缀 → `e`                   |
| 左/下/上/右窗格       | 前缀 → `h` / `j` / `k` / `l` |
| 下/上一个窗格         | 前缀 → `Tab` / `Shift+Tab`   |
| 向右分割            | 前缀 → `v`                   |
| 向下分割            | 前缀 → `-`                   |
| 关闭窗格            | 前缀 → `x`                   |
| 放大/恢复窗格         | 前缀 → `z`                   |
| 调整尺寸模式          | 前缀 → `r`                   |
| 切换侧栏            | 前缀 → `b`                   |

在直接 attach 中，Ctrl+B 连按两次可向程序发送字面 Ctrl+B。需要精确的本机配置时，以 `--default-config` 和当前 `config.toml` 为准，不能假定默认键一定未被终端或操作系统截获。
