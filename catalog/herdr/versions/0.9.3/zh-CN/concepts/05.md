---
title: 5. --kind 的 24 个规范 Agent 名称
---

这些是该版本源码中的 Agent 类型枚举，不是“所有类型具有完全相同集成能力”的承诺。程序仍需自行安装并完成登录配置。以下名称可以作为 `agent start --kind` 的规范值。[S01](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/spec.rs#L6-L966)[S18](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/detect/mod.rs)

| 规范 KIND      | 规范启动程序         | 备注                                            |
| ------------ | -------------- | --------------------------------------------- |
| `pi`         | `pi`           |                                               |
| `claude`     | `claude`       | 识别别名含 `claude-code`                           |
| `codex`      | `codex`        |                                               |
| `gemini`     | `gemini`       |                                               |
| `cursor`     | `cursor-agent` | Windows 对应启动程序可能使用 `.cmd`                     |
| `devin`      | `devin`        | 别名含 `devin-cli`、`devin cli`                   |
| `agy`        | `agy`          | 识别别名含 `antigravity`、`antigravity-cli`         |
| `cline`      | `cline`        | 识别别名含 `.cline`                                |
| `omp`        | `omp`          |                                               |
| `mastracode` | `mastracode`   | 别名含 `mastra-code`、`mastra code`               |
| `opencode`   | `opencode`     | 别名含 `opencode2`、`open-code`                   |
| `copilot`    | `copilot`      | 别名含 `github-copilot`、`ghcs`                   |
| `kimi`       | `kimi`         | 别名含 `kimi-code`、`kimi code`                   |
| `kiro`       | `kiro-cli`     |                                               |
| `droid`      | `droid`        |                                               |
| `amp`        | `amp`          | 识别别名含 `amp-local`                             |
| `grok`       | `grok`         | 识别别名含 `grok-build`                            |
| `hermes`     | `hermes`       | 识别别名含 `hermes-agent`                          |
| `kilo`       | `kilo`         | 别名含 `kilo-code`、`kilo code`                   |
| `qodercli`   | `qodercli`     | 别名含 `qoderclicn`、`qoder`、`qodercn`            |
| `qwen`       | `qwen`         | 别名含 `qwen-code`、`qwen code`                   |
| `letta`      | `letta`        | 内置集成目标仍列为实验性                                  |
| `maki`       | `maki`         |                                               |
| `muse`       | `muse`         | 别名含 `muse-code`、`muse-cli`，识别版本化 `muse-bin-*` |

别名表描述检测/名称归一化路径，不代表每一种别名都在 `--help` 的枚举里显示。调用示例优先使用左侧规范 KIND。
