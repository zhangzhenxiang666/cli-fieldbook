---
title: 4. 输出快照来源与行数
---

| `--source`         | 选择什么                    | 主要用途            |
| ------------------ | ----------------------- | --------------- |
| `visible`          | 当前渲染的可见屏幕               | 查看菜单、确认框、当前 TUI |
| `recent`           | 终端近期输出/滚动历史，保留读取视图中的软换行 | 常规日志检查；默认来源     |
| `recent-unwrapped` | 近期输出合并软换行               | 阅读长命令、较长回答、长日志  |
| `detection`        | 状态检测使用的底部快照             | 排查识别问题，不代表全部日志  |

近期快照默认取最后 **80 个渲染行**；显式 `--lines N` 限制行数。合并软换行发生在选择渲染行之后，所以 80 个渲染行不一定等于 80 条完整日志。`visible` / `detection` 使用各自完整视图，显式行数再截取；不要把所有来源都理解成同一个 80 行缓存。

`pane read` / `agent read` 的 `--format text|ansi` 和 `--ansi` 控制输出格式。`pane read` 另有 `--raw`，`agent read` 没有。`detection` 是检测用纯文本视图，不是重放原始控制序列的途径。

`pane wait-output` 的公开来源集合只有 visible、recent、recent-unwrapped。匹配先检查已有快照；recent 两种来源的匹配会合并软换行。`--regex` 使用 Rust 正则且逐行匹配，不能把它当成任意 PCRE 或跨多行全文正则。`--raw` 保留 ANSI 会使颜色/控制码参与匹配，可能导致表面相同的字符串不命中。

运行时还接受 `recent_unwrapped` 兼容拼写；文档和脚本统一使用 `recent-unwrapped`。[S01](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/spec.rs#L6-L966)[S03](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli.rs)[S04](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/pane.rs)
