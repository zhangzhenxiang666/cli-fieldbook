---
title: 2. detach、停止、关闭、恢复不是同一件事
---

| 操作                                             | 实际意图                | 需要警惕               |
| ---------------------------------------------- | ------------------- | ------------------ |
| TUI 的 detach                                   | 离开客户端，server 继续托管终端 | 不会自动“完成”后台任务       |
| `server stop` / `session stop`                 | 停止托管会话              | 会影响该 server 下的真实进程 |
| `pane close` / `tab close` / `workspace close` | 关闭对应运行对象            | 会影响其中的终端任务         |
| `session delete`                               | 删除已停止会话的保存状态        | 不是普通清理屏幕操作         |
| `worktree remove`                              | 删除 Git checkout     | 比关闭 Herdr 工作区风险更高  |

Server 重启后恢复工作区结构，并不意味着原进程及其内存原样存活。配置允许恢复支持的 Agent 会话，也依赖 Agent 提供可恢复的会话身份/启动参数；不要据此推断任意 shell 命令都能续跑。

实验性的 live handoff 是另一条运行中交接路径，不应与普通持久会话恢复混为一谈。默认工作流使用常规更新和显式重启；只有理解版本/协议兼容风险时才考虑 handoff。[S02](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/main.rs)[S04](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/pane.rs)[S06](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/workspace.rs)[S07](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/worktree.rs)[S13](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/server.rs)
