---
title: 10. 配置、环境变量与展示模板
---

默认配置可由当前版本二进制直接导出：

```bash
herdr --default-config > herdr-default.toml
herdr config check
```

常见 Unix 配置路径为 `~/.config/herdr/config.toml`；`HERDR_CONFIG_PATH` 可显式覆盖。跨平台路径以该二进制的 `herdr --help` 与实际平台解析为准。本节是与 CLI 操作直接相关的配置摘要，不冒充整个应用配置 schema。

| 配置项                                      | v0.9.3 内置默认/用途                      |
| ---------------------------------------- | ----------------------------------- |
| `terminal.new_cwd`                       | `follow`，跟随当前目录策略                   |
| `server.headless_cols` / `headless_rows` | `120` / `40`                        |
| `worktrees.directory`                    | `~/.herdr/worktrees`                |
| `session.resume_agents_on_restore`       | `true`，尝试恢复支持的 Agent 会话             |
| `session.startup_per_agent_delay_ms`     | `100`                               |
| `experimental.pane_history`              | `false`                             |
| `ui.window_title`                        | `{hostname}: {workspace}`           |
| `ui.toast.delivery`                      | `off`；其他投递方式有 herdr、terminal、system |
| `ui.toast.herdr.position`                | `bottom-right`                      |

相关环境变量摘要：

| 变量                    | 用途                         |
| --------------------- | -------------------------- |
| `HERDR_CONFIG_PATH`   | 显式指定配置路径                   |
| `HERDR_SESSION`       | 命名会话选择                     |
| `HERDR_SOCKET_PATH`   | API socket 路径覆盖，通常用于高级连接场景 |
| `HERDR_ENV`           | Herdr 管理的环境标记              |
| `HERDR_PANE_ID`       | 当前进程所属窗格                   |
| `HERDR_TAB_ID`        | 当前进程所属标签页                  |
| `HERDR_WORKSPACE_ID`  | 当前进程所属工作区                  |
| `HERDR_LOG`           | 日志过滤配置，例如 `herdr=debug`    |
| `HERDR_DISABLE_SOUND` | 禁用声音的环境开关                  |

`ui.window_title` 的占位符包含 `{hostname}`、`{workspace}`、`{tab}`、`{pane}`、`{terminal_title}`，用 `{{` / `}}` 表示字面花括号。自定义展示元数据的 token 可以在支持的侧栏配置位置以 `$name` 形式引用。

注意双重解释：shell 会先展开 `$name`，Herdr 配置才处理自己的 token。需要把字面 `$build` 写到配置/参数时使用单引号或正确转义。展示 token 不是 jj revset，Herdr 也没有 jj 那种 revision 集合表达式系统。[S02](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/main.rs)[S03](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli.rs)[S04](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/pane.rs)[S06](https://github.com/herdrdev/herdr/blob/7b116c05bfda646af39d2524c54e70c751f57ee8/src/cli/workspace.rs)
