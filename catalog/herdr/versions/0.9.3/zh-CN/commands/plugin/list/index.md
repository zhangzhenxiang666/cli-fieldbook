## 简介

列出插件及状态。

## 选项

### `--plugin`

仅查看指定插件。

### `--json`

输出 JSON，而不是默认的人类可读格式。具体结构以本命令为准，不假定都有 result 外层。

### `--help`

打印该命令的帮助。
