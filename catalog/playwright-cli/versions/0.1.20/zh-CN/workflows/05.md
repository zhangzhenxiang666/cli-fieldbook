**适用场景：** 把手工验证过的交互序列沉淀为可复用的 Playwright 代码：录制操作、生成定位器、必要时直接运行代码片段。

## 前提

- 会话已打开目标页面。
- 明确要沉淀的操作序列（登录流、关键路径等）。

## 步骤

### 1. 录制操作

```sh
playwright-cli recording-start
# ……在浏览器或 CLI 中执行操作（click/fill/goto 等）
playwright-cli recording-stop
```

[recording-start](cli:command:recording-start) 开始录制，[recording-stop](cli:command:recording-stop) 停止并打印等价的 Playwright 代码。完成信号：输出的代码覆盖录制期间的每一步操作。

### 2. 沉淀定位器

```sh
playwright-cli generate-locator e5 --raw
```

[generate-locator](cli:command:generate-locator) 把快照引用转为推荐的 Playwright 定位器（角色/测试标识优先），比裸引用更适合写进测试。完成信号：输出一条可用的定位器表达式。

### 3. 代码片段验证

```sh
playwright-cli run-code "async page => await page.context().grantPermissions(['geolocation'])"
playwright-cli run-code --filename=script.js
```

[run-code](cli:command:run-code) 以 `page` 为参数执行任意 Playwright API，用于命令行未覆盖的操作（授予权限、多选下拉、复杂等待）。片段稳定后移入正式测试。

**风险与边界：** 录制代码与生成的定位器是起点而非成品：等待条件、断言与选择器稳定性需要人工复核；`run-code` 执行任意代码，片段内容应可审查。

**未实测声明：** 本工作流依据 `@playwright/cli` 0.1.20 固定提交源码与官方 skills 文档快照编写，命令组合与预期输出未在真实环境实测。
