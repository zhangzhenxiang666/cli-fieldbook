**适用场景：** 为一次页面操作留下可回放的证据：trace 供事后逐步分析，视频供演示与评审附件；UI 改动请人看效果时用标注评审。

## 前提

- 会话已打开；知道要记录的操作范围（从哪步开始、到哪步结束）。
- 需要 PR 附件时本机有 `gh` 2.99+。

## 步骤

### 1. 起录

```sh
playwright-cli tracing-start
playwright-cli video-start video.webm
playwright-cli video-show-actions --duration=600
```

[tracing-start](cli:command:tracing-start) 记录操作序列与网络/控制台快照；[video-start](cli:command:video-start) 录制画面（`--size="800x600"` 可指定尺寸）；[video-show-actions](cli:command:video-show-actions) 让后续每个操作在画面上以标注框呈现（操作名 + 高亮目标）。

### 2. 执行要记录的操作，打章节

```sh
playwright-cli click e5
playwright-cli video-chapter "提交表单" --description="含校验失败分支"
playwright-cli fill e7 "test"
```

[video-chapter](cli:command:video-chapter) 在关键节点插章节卡片，方便评审跳转。

### 3. 停录与产物

```sh
playwright-cli video-stop
playwright-cli tracing-stop
```

完成信号：trace 文件与视频文件生成。trace 在 Playwright Trace Viewer 中逐步回放；视频可直接观看。

### 4. 作为 PR 附件

```sh
playwright-cli screenshot --filename=settings-after.png
gh pr comment 123 --body "Settings page after the fix." --attach ./settings-after.png
```

`gh` 2.99+ 的 `--attach` 支持图片与视频：UI 修复、前后对比、新用户流程或缺陷现场，一张截图常能让评审者免去本地复现。

### 5.（替代路线）标注评审

```sh
playwright-cli open https://example.com
playwright-cli show --annotate
```

[show --annotate](cli:command:show) 让用户在实时页面上画框写注释，随后返回带标注的截图、区域快照与笔记——适合"请人看效果/给设计反馈"的场景。

**风险与边界：** 录制会改变产物体积与页面开销，范围要收敛；视频含页面真实内容，外发前确认无敏感信息。
