**适用场景：** 并行推进多个任务（各用独立会话互不干扰），或借用本机已在运行的浏览器（含浏览器扩展）作为操作对象。

## 前提

- 理解会话命名：`-s=<name>`，缺省 `default`（见[会话与工作区](../concepts/sessions.md)）。
- attach 本机 Chrome/Edge 时该浏览器需以远程调试方式可用；`--cdp=<url>` 需知道端点地址。

## 步骤

### 1. 并行两个任务会话

```sh
playwright-cli -s=test open https://staging.example.com
playwright-cli -s=docs open https://playwright.dev
playwright-cli -s=test click e3
playwright-cli -s=docs snapshot
```

每条命令按 `-s` 路由到对应会话；会话按工作区隔离，`list` 缺省只看本工作区。

### 2. 连接本机正在运行的浏览器

```sh
playwright-cli attach --cdp=chrome
playwright-cli attach --cdp=msedge
playwright-cli attach --extension=chrome
```

通道名（`chrome`/`msedge`）连接本机对应浏览器，`--cdp=http://localhost:9222` 连任意 CDP 端点，`--extension` 连 Playwright 浏览器扩展。会话名缺省取目标名。完成信号：attach 返回快照。

### 3. 盘点与收尾

```sh
playwright-cli list --all
playwright-cli -s=msedge detach
playwright-cli close-all
```

[list --all](cli:command:list) 跨工作区盘点；attached 会话用 [detach](cli:command:detach) 分离（外部浏览器继续运行），自启动的用 [close](cli:command:close)；[close-all](cli:command:close-all) 批量关闭当前工作区会话。

### 4. 兜底清理

```sh
playwright-cli kill-all
```

守护进程残留、会话关不掉时按进程特征强杀。完成信号：输出被终止的进程号列表；之后 `list` 为空。

**风险与边界：** `kill-all` 按进程命令行特征匹配，可能波及用户自己启动的 Playwright 相关进程，仅在清理失效时使用；attach 的浏览器由外部管理，`close` 会把它一并关掉，结束连接用 `detach`。
