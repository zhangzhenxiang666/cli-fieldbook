**适用场景：** 从零开始使用 playwright-cli：安装命令、初始化工作区、打开第一个页面并完成一次交互，理解"会话"的基本循环。

## 前提

- Node.js 20 及以上。`@playwright/cli` 自身的 engines 声明为 `>=18`，但其精确依赖的 `playwright-core@1.64.0-alpha-2026-09-14` 声明 `>=20`，以更严者为准。全局安装 `npm install -g @playwright/cli` 后获得 `playwright-cli` 命令；本地项目装有提供 `cli` 子命令的 Playwright 版本时，也可用 `npx playwright cli` 替代下文全部命令（先用 `npx --no-install playwright --version` 确认本地版本可用）。
- `playwright-cli --version` 应输出 `0.1.20`。

## 步骤

### 1.（可选）初始化工作区与 skills

```sh
playwright-cli install
```

在当前目录创建 `.playwright/` 工作区配置；`--skills=claude`（缺省）或 `--skills=agents` 同时安装官方 agent skills 文档，加 `-g` 装到主目录。注意：非 `--global` 运行时，工作区初始化会确保配置的浏览器已安装——本机没有可用浏览器时会在此步触发浏览器下载（设 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1` 可跳过，改用第 2 步自行控制）。完成信号：命令无报错退出，目录中出现工作区配置。

### 2.（按需）安装浏览器二进制

```sh
playwright-cli install-browser
```

本机尚无所需浏览器时执行；已有则跳过。`--list` 查看已装清单，`--dry-run` 预览将执行的动作。完成信号：输出安装完成信息。

### 3. 打开会话并导航

```sh
playwright-cli open https://playwright.dev
```

启动无头浏览器会话（缺省 Chromium、内存 profile），隐式执行一次 [goto](cli:command:goto) 并返回首个快照。完成信号：响应包含页面 URL、标题与快照链接。

### 4. 观察与交互一轮

```sh
playwright-cli snapshot
playwright-cli find "Get started"
playwright-cli click e15
```

[snapshot](cli:command:snapshot) 拿到带元素引用的结构；[find](cli:command:find) 在快照中检索目标；用引用 `e15` [click](cli:command:click)。每条命令完成后自动附带新快照，形成"看—找—点"的循环。完成信号：每次命令返回新的页面状态。

### 5. 结束会话

```sh
playwright-cli close
```

停止会话与守护进程。内存 profile 的页面状态随之丢弃；持久会话数据用 [delete-data](cli:command:delete-data) 清除。

**风险与边界：** 无头缺省 1 小时空闲后自动关闭（`--idle-timeout` 控制）；机器重启后守护进程不在，需要重新 `open`。
