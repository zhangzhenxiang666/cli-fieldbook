**适用场景：** 在桌面与移动视口下检查同一页面（响应式布局、移动端交互），以及在多个标签页之间切换操作对象。

## 前提

- 尚未打开会话（设备仿真在 `open` 时指定）；或已有会话用于中途调整视口。

## 步骤

### 1. 以移动形态打开

```sh
playwright-cli open --mobile https://example.com
playwright-cli open --device="iPhone 15" https://example.com
```

`--mobile` 仿真通用移动设备（Chromium 用 Pixel 10、WebKit 用 iPhone 17），页面通常更轻、快照更小；`--device` 仿真特定机型。完成信号：快照中的视口与元素布局呈移动形态。

### 2. 桌面对照

```sh
playwright-cli -s=desktop open https://example.com
```

另开会话做桌面对照，或在一个会话内用 [resize](cli:command:resize) 直接改视口：`playwright-cli resize 1920 1080`。

### 3. 多标签页操作

```sh
playwright-cli tab-new https://example.com/docs
playwright-cli tab-list
playwright-cli tab-select 0
playwright-cli snapshot
```

[tab-new](cli:command:tab-new) 新建并切换；[tab-list](cli:command:tab-list) 列出索引；[tab-select](cli:command:tab-select) 切换当前页，后续命令作用于它；[tab-close](cli:command:tab-close) 关闭指定索引或当前页。完成信号：`tab-list` 显示预期标签页集合，`tab-select` 后快照为所选页面。

**风险与边界：** 设备仿真改变视口与 user agent，但不等于真机（触摸硬件、性能特征不同）；`tab-close` 不带索引关闭的是当前页，注意别关错。
