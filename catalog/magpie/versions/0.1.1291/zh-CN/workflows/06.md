# 工作流:用量与配额监控

回答三个日常问题:花了多少、哪个会话花的、还剩多少。

## 前置条件

- magpie 网关在跑(用量随请求积累);
- (可选)想看费用金额的模型已在 models.dev 目录或经 [`magpie model price`](cli:command:model/price) 定价。

## 花了多少:usage

- [`magpie usage`](cli:command:usage):默认 30 天,按 agent、模型、订阅账户汇总 token 与费用;`today`/`7d`/`all` 换窗口;
- `--last 24h`/`--days 7`:以现在为终点的滚动窗口(不从午夜起算);
- `--csv`:每请求一条 CSV(要求模型、发送模型、实际服务模型、token、费用、时间、状态、账户),适合进表格分析;`--account` 只看一个账户。

## 哪个会话花的:sessions

- [`magpie sessions`](cli:command:sessions):最近的 Claude Code、Codex、OpenCode、Pi 会话及各自费用;`--model`/`--folder` 过滤;
- `--days 7`(或 today/all):逐日汇总,附最高模型与文件夹。

## 还剩多少:quota

- [`magpie quota`](cli:command:quota):每个订阅、计划、key 余额的剩余与重置窗口;`--json` 供脚本;
- [`magpie quota history`](cli:command:quota/history):45 天内各窗口的读数走势;
- [`magpie quota wait claude --timeout 2h`](cli:command:quota/wait):脚本里阻塞等额度恢复。

## 常驻可见:statusline

把 [`magpie statusline`](cli:command:statusline) 配成 Claude Code 状态栏:一行显示会话模型与各账户窗口,不用主动查询。

## 完成信号

- `magpie usage today` 数字与实际使用一致;
- 订阅耗尽前后,quota 与路由组行为互相印证(自动换号)。

## 失败与恢复

- 费用显示为 0:模型不在目录或未定价,用 `magpie model price <provider/model> <in>,<out>,<cr>,<cw>` 手工定价;
- 多机共用网关时各自记账:usage 同步(`webdav/s3/github set usage=yes`)后 Usage 页汇总各机器。
