Manage resource tags

Usage:
  coolify tag [command]

Aliases:
  tag, tags

Available Commands:
  create      Create a team tag
  delete      Delete a team tag
  list        List all team tags
  update      Rename a team tag

Flags:
  -h, --help   help for tag

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify tag [command] --help" for more information about a command.
