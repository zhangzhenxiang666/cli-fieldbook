Deploy by resource name

Usage:
  coolify deploy name <resource_name> [flags]

Flags:
      --docker-tag string     Docker image tag override for the deployment
      --force                 Force deployment
  -h, --help                  help for name
      --pull-request-id int   Pull request ID for preview deployments

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
