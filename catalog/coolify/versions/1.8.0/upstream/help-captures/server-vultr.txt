Provision servers with Vultr

Usage:
  coolify server vultr [command]

Available Commands:
  create      Create a Vultr server
  os          List Vultr operating systems
  plans       List Vultr plans
  regions     List Vultr regions
  ssh-keys    List Vultr SSH keys

Flags:
  -h, --help   help for vultr

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server vultr [command] --help" for more information about a command.
