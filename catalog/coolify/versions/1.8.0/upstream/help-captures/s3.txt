Manage S3-compatible storage destinations

Usage:
  coolify s3 [command]

Aliases:
  s3, s3-storage, s3-storages

Available Commands:
  create      Create an S3 storage
  delete      Delete an S3 storage
  get         Get an S3 storage
  list        List S3 storages
  update      Update an S3 storage
  validate    Validate S3 connection

Flags:
  -h, --help   help for s3

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify s3 [command] --help" for more information about a command.
