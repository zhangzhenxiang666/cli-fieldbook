Create a new environment in a project.

Examples:
  coolify project environments create <project_uuid> --name staging

Usage:
  coolify project environments create <project_uuid> [flags]

Flags:
  -h, --help          help for create
      --name string   Environment name (required)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
