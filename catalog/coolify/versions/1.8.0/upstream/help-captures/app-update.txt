Update configuration for a specific application. Only specified fields will be updated.

Docker Compose domains are supplied as the complete service-to-domain mapping for the update.

Example:
  coolify app update <uuid> --compose-domain "api=https://api.example.com" \
    --compose-domain "admin=https://admin.example.com,https://admin2.example.com"

Usage:
  coolify app update <uuid> [flags]

Flags:
      --base-directory string                  Base directory
      --build-command string                   Build command
      --compose-domain stringArray             Docker Compose service domain in <service>=<url>[,<url>] format (repeatable)
      --custom-internal-name string            Custom internal hostname
      --description string                     Application description
      --disable-build-cache                    Disable the build cache
      --docker-image string                    Docker image name
      --docker-images-to-keep int              Number of Docker images to retain
      --docker-tag string                      Docker image tag
      --dockerfile string                      Dockerfile content
      --dockerfile-target-build string         Dockerfile target build stage
      --domains string                         Domains (comma-separated)
      --git-branch string                      Git branch
      --git-repository string                  Git repository URL
      --gpu-count string                       GPU count
      --gpu-device-ids string                  GPU device IDs
      --gpu-driver string                      GPU driver
      --gpu-options string                     GPU options
      --health-check-enabled                   Enable health check
      --health-check-path string               Health check path
  -h, --help                                   help for update
      --include-source-commit-in-build         Include the source commit in the build
      --inject-build-args-to-dockerfile        Inject build arguments into the Dockerfile
      --install-command string                 Install command
      --is-consistent-container-name-enabled   Use consistent container names
      --is-env-sorting-enabled                 Sort environment variables
      --is-git-lfs-enabled                     Enable Git LFS
      --is-git-shallow-clone-enabled           Use a shallow Git clone
      --is-git-submodules-enabled              Clone Git submodules
      --is-gpu-enabled                         Enable GPU
      --is-gzip-enabled                        Enable gzip compression
      --is-log-drain-enabled                   Enable application log drain
      --is-pr-deployments-public-enabled       Make pull request deployments public
      --is-preview-deployments-enabled         Enable preview deployments
      --is-raw-compose-deployment-enabled      Deploy the raw Docker Compose definition
      --is-stripprefix-enabled                 Enable path prefix stripping
      --max-restart-count int                  Maximum container restart count
      --name string                            Application name
      --ports-exposes string                   Exposed ports
      --ports-mappings string                  Port mappings
      --preview-url-template string            Preview URL template
      --publish-directory string               Publish directory
      --start-command string                   Start command
      --stop-grace-period int                  Container stop grace period in seconds
      --use-build-secrets                      Use Docker Build Secrets for build-time variables

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
