Manage preview deployments created from pull requests. Requires the application UUID.

Usage:
  coolify app previews [command]

Aliases:
  previews, preview

Available Commands:
  delete      Delete a preview deployment

Flags:
  -h, --help   help for previews

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app previews [command] --help" for more information about a command.
