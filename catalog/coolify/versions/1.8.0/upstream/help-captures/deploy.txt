Deploy related commands

Usage:
  coolify deploy [command]

Available Commands:
  batch       Deploy multiple resources by name
  cancel      Cancel a deployment by UUID
  get         Get deployment details by UUID
  list        List all deployments
  name        Deploy by resource name
  uuid        Deploy by uuid

Flags:
  -h, --help   help for deploy

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify deploy [command] --help" for more information about a command.
