Manage service environment variables

Usage:
  coolify service env [command]

Available Commands:
  create      Create an environment variable for a service
  delete      Delete an environment variable
  get         Get environment variable details
  list        List all environment variables for a service
  sync        Sync environment variables from a .env file
  update      Update an environment variable

Flags:
  -h, --help   help for env

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service env [command] --help" for more information about a command.
