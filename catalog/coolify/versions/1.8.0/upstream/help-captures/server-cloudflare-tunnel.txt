Manage Cloudflare Tunnel settings

Usage:
  coolify server cloudflare-tunnel [command]

Aliases:
  cloudflare-tunnel, cf-tunnel

Available Commands:
  disable     Disable Cloudflare tunnel flag
  enable      Enable Cloudflare tunnel flag
  get         Get Cloudflare tunnel state
  update      Set Cloudflare tunnel enabled state

Flags:
  -h, --help   help for cloudflare-tunnel

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server cloudflare-tunnel [command] --help" for more information about a command.
