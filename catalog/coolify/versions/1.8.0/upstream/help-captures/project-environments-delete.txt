Delete an environment by name or UUID. The environment must be empty.

Examples:
  coolify project environments delete <project_uuid> staging
  coolify project environments delete <project_uuid> <env_uuid> --force

Usage:
  coolify project environments delete <project_uuid> <environment> [flags]

Flags:
  -f, --force   Skip confirmation prompt
  -h, --help    help for delete

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
