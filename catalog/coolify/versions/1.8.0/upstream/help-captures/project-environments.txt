List, create, update, and delete environments within a project.

Usage:
  coolify project environments [command]

Aliases:
  environments, environment, env

Available Commands:
  create      Create an environment in a project
  delete      Delete a project environment
  list        List environments in a project
  update      Update a project environment

Flags:
  -h, --help   help for environments

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify project environments [command] --help" for more information about a command.
