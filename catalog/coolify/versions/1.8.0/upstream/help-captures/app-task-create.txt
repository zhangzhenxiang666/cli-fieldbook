Create a scheduled task for an application.

Examples:
  coolify app task create <app_uuid> --name backup --command "php artisan backup:run" --frequency "0 2 * * *"
  coolify app task create <app_uuid> --name cleanup --command "rm -rf /tmp/*" --frequency daily --timeout 120 --enabled=false

Usage:
  coolify app task create <app_uuid> [flags]

Flags:
      --command string     Command to run (required)
      --container string   Container name to run the command in
      --enabled            Whether the task is enabled (default true)
      --frequency string   Cron expression or frequency (required)
  -h, --help               help for create
      --name string        Task name (required)
      --timeout int        Timeout in seconds (default 300)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
