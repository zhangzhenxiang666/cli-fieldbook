Provision servers with Hetzner

Usage:
  coolify server hetzner [command]

Available Commands:
  create       Create a Hetzner server
  firewalls    List Hetzner firewalls
  images       List Hetzner images
  locations    List Hetzner locations
  networks     List Hetzner networks
  server-types List Hetzner server types
  ssh-keys     List Hetzner SSH keys

Flags:
  -h, --help   help for hetzner

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server hetzner [command] --help" for more information about a command.
