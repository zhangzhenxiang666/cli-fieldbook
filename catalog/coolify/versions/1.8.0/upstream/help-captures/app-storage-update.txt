Update a persistent volume or file storage for an application.

The --uuid and --type flags are required. Use 'coolify app storage list' to find storage UUIDs.

For read-only storages (from docker-compose or services), only --is-preview-suffix-enabled can be updated.

Examples:
  coolify app storage update <app_uuid> --uuid <storage_uuid> --type persistent --name my-volume --mount-path /data
  coolify app storage update <app_uuid> --uuid <storage_uuid> --type file --content "config content" --mount-path /app/config.yml
  coolify app storage update <app_uuid> --uuid <storage_uuid> --type persistent --is-preview-suffix-enabled

Usage:
  coolify app storage update <app_uuid> [flags]

Flags:
      --content string              File content (file only)
  -h, --help                        help for update
      --host-path string            Host path (persistent only)
      --id int                      Storage ID (deprecated, use --uuid instead)
      --is-preview-suffix-enabled   Enable preview suffix for this storage
      --mount-path string           Mount path inside the container
      --name string                 Storage name (persistent only)
      --type string                 Storage type: 'persistent' or 'file' (required)
      --uuid string                 Storage UUID (required, use 'storage list' to find)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
