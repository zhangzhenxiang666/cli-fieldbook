Create a persistent volume or file storage for a service.

The --resource-uuid flag is required to specify which service sub-resource
(application or database) the storage belongs to.

Examples:
  coolify svc storage create <service_uuid> --resource-uuid <sub_resource_uuid> --type persistent --name my-volume --mount-path /data
  coolify svc storage create <service_uuid> --resource-uuid <sub_resource_uuid> --type file --mount-path /app/config.yml --content "key: value"

Usage:
  coolify service storage create <service_uuid> [flags]

Flags:
      --content string         File content (file only)
      --fs-path string         Host directory path (file only, required when --is-directory is set)
  -h, --help                   help for create
      --host-path string       Host path (persistent only)
      --is-directory           Whether this is a directory mount (file only)
      --mount-path string      Mount path inside the container (required)
      --name string            Volume name (persistent only)
      --resource-uuid string   UUID of the service sub-resource (required)
      --type string            Storage type: 'persistent' or 'file' (required)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
