Update a project's name and/or description.

Examples:
  coolify project update <uuid> --name "New Name"
  coolify project update <uuid> --description "New description"
  coolify project update <uuid> --name "New Name" --description "New description"

Usage:
  coolify project update <uuid> [flags]

Flags:
      --description string   Project description
  -h, --help                 help for update
      --name string          Project name

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
