Team-level shared envs (/team/envs)

Usage:
  coolify shared-env team [command]

Available Commands:
  create      Create team shared env
  delete      Delete team shared env
  list        List team shared envs
  update      Update team shared env

Flags:
  -h, --help   help for team

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify shared-env team [command] --help" for more information about a command.
