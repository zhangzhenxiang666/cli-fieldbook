Manage Coolify databases (PostgreSQL, MySQL, MongoDB, Redis, MariaDB, KeyDB, Clickhouse, Dragonfly).

Usage:
  coolify database [command]

Aliases:
  database, databases, db, dbs

Available Commands:
  backup             Manage database backups
  clone              Clone a database to a destination
  create             Create a new database
  delete             Delete a database
  env                Manage database environment variables
  get                Get database details
  list               List all databases
  logs               Get database logs
  move               Move a database to another environment
  restart            Restart a database
  run-storage-backup Run a volume backup schedule now
  start              Start a database
  stop               Stop a database
  storage            Manage database storages
  tag                Manage database tags
  update             Update a database

Flags:
  -h, --help   help for database

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify database [command] --help" for more information about a command.
