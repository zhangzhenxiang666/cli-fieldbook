List and manage persistent volumes and file storages for services.

Usage:
  coolify service storage [command]

Aliases:
  storage, storages

Available Commands:
  create        Create a storage for a service
  delete        Delete a storage from a service
  delete-backup Delete service storage volume backup schedule
  list          List all storages for a service
  run-backup    Run service storage volume backup now
  set-backup    Create or replace service storage volume backup schedule
  update        Update a storage for a service

Flags:
  -h, --help   help for storage

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service storage [command] --help" for more information about a command.
