Update an application in a service

Usage:
  coolify service application update <service-uuid> <application-uuid> [flags]

Flags:
      --description string      Description
      --exclude-from-status     Exclude from service status
      --force-domain-override   Allow conflicting or duplicate domains
      --gzip-enabled            Enable gzip compression
  -h, --help                    help for update
      --human-name string       Human-readable name
      --image string            Container image
      --log-drain-enabled       Enable log drain
      --stripprefix-enabled     Enable path prefix stripping
      --url string              Comma-separated public URLs

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
