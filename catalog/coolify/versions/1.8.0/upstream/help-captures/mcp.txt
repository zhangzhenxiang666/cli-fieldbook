Enable or disable the Coolify MCP server. Requires a root team API token.

Usage:
  coolify mcp [command]

Available Commands:
  disable     Disable the MCP server
  enable      Enable the MCP server

Flags:
  -h, --help   help for mcp

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify mcp [command] --help" for more information about a command.
