Team, project, environment, and server shared env vars (inherited by resources).

Usage:
  coolify shared-env [command]

Aliases:
  shared-env, shared-envs, sharedenv

Available Commands:
  environment Environment-level shared envs
  project     Project-level shared envs
  server      Server-level shared envs
  team        Team-level shared envs (/team/envs)

Flags:
  -h, --help   help for shared-env

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify shared-env [command] --help" for more information about a command.
