Requires a root-team API token belonging to a root-team admin or owner.

Usage:
  coolify settings email [command]

Available Commands:
  get         Get instance email settings
  update      Update instance email settings

Flags:
  -h, --help   help for email

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify settings email [command] --help" for more information about a command.
