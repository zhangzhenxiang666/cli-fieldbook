Manage team notification channel settings

Usage:
  coolify notification [command]

Aliases:
  notification, notifications

Available Commands:
  get         Get notification settings for a channel
  update      Update notification settings (JSON body)

Flags:
  -h, --help   help for notification

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify notification [command] --help" for more information about a command.
