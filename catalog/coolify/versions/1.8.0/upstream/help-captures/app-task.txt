List, create, update, delete, and execute scheduled tasks for applications.

Usage:
  coolify app task [command]

Aliases:
  task, tasks, scheduled-task, scheduled-tasks

Available Commands:
  create      Create a scheduled task for an application
  delete      Delete an application scheduled task
  execute     Execute an application scheduled task now
  executions  List executions for an application scheduled task
  list        List scheduled tasks for an application
  update      Update an application scheduled task

Flags:
  -h, --help   help for task

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app task [command] --help" for more information about a command.
