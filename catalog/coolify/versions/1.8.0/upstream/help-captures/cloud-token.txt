Manage cloud provider API tokens

Usage:
  coolify cloud-token [command]

Aliases:
  cloud-token, cloud-tokens

Available Commands:
  create      Create a cloud provider token
  delete      Delete a cloud provider token
  get         Show a cloud provider token
  list        List cloud provider tokens
  update      Rename a cloud provider token
  validate    Validate a cloud provider token

Flags:
  -h, --help   help for cloud-token

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify cloud-token [command] --help" for more information about a command.
