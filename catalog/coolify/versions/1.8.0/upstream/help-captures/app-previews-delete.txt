Delete a preview deployment for an application. First argument is the application UUID, second is the pull request ID.

Usage:
  coolify app previews delete <app_uuid> <pr_id> [flags]

Flags:
      --force   Skip confirmation prompt
  -h, --help    help for delete

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
