Manage server Sentinel/metrics settings

Usage:
  coolify server sentinel [command]

Available Commands:
  get         Get Sentinel settings
  update      Update Sentinel settings via JSON

Flags:
  -h, --help   help for sentinel

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server sentinel [command] --help" for more information about a command.
