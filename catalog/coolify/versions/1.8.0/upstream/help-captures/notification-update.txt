Pass settings as JSON via --json. Example: coolify notification update webhook --json '{"webhook_enabled":true}'

Usage:
  coolify notification update <channel> [flags]

Flags:
  -h, --help          help for update
      --json string   JSON object of fields to update

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
