Add a server

Usage:
  coolify server add <server_name> <ip_address> <private_key_uuid> [flags]

Flags:
  -h, --help          help for add
  -p, --port int      Port (default 22)
  -u, --user string   User (default "root")
      --validate      Validate the server

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
