Application rollback helpers

Usage:
  coolify app rollback [command]

Available Commands:
  images      List rollback images
  run         Rollback application to a commit

Flags:
  -h, --help   help for rollback

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app rollback [command] --help" for more information about a command.
