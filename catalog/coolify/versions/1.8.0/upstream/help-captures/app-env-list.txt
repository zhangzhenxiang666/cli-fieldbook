List all environment variables for a specific application. By default, only non-preview environment variables are shown. Use --preview to show preview environment variables instead, or --all to show all variables (non-preview first, then preview).

Usage:
  coolify app env list <app_uuid> [flags]

Flags:
      --all       Show all environment variables (non-preview first, then preview)
  -h, --help      help for list
      --preview   Show preview environment variables instead of regular ones

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
