Manage Coolify applications - list, get, create, update, delete, and control application lifecycle.

Usage:
  coolify app [command]

Aliases:
  app, apps, application, applications

Available Commands:
  clone              Clone an application to a destination
  create             Create a new application
  delete             Delete an application
  deployments        Deployment related commands for an application
  destinations       Manage application additional destinations
  env                Manage application environment variables
  execute-task       Execute a scheduled task now
  get                Get application details by UUID
  list               List all applications
  logs               Get application logs
  move               Move an application to another environment
  previews           Manage application preview deployments
  restart            Restart an application
  rollback           Application rollback helpers
  run-storage-backup Run volume backup schedule now
  start              Start an application
  stop               Stop an application
  storage            Manage application storages
  tag                Manage application tags
  task               Manage application scheduled tasks
  update             Update application configuration

Flags:
  -h, --help   help for app

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app [command] --help" for more information about a command.
