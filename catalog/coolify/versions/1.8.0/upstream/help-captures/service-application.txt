Manage applications within a service

Usage:
  coolify service application [command]

Aliases:
  application, applications, app, apps

Available Commands:
  get         Get an application in a service
  list        List applications in a service
  logs        Get logs for an application in a service
  restart     Restart an application in a service
  start       Start or redeploy an application in a service
  stop        Stop an application in a service
  update      Update an application in a service

Flags:
  -h, --help   help for application

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service application [command] --help" for more information about a command.
