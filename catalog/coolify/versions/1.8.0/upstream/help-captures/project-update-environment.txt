Update a project environment. Prefer: coolify project environments update

Usage:
  coolify project update-environment <project_uuid> <environment> [flags]

Flags:
      --description string   Environment description
  -h, --help                 help for update-environment
      --name string          Environment name

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
