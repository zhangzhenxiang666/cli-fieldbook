Create an S3 storage

Usage:
  coolify s3 create [flags]

Flags:
      --bucket string        Bucket name
      --description string   Description
      --endpoint string      S3 endpoint URL
  -h, --help                 help for create
      --key string           Access key
      --name string          Storage name
      --region string        Region
      --secret string        Secret key
      --usable               Mark storage as usable (default true)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
