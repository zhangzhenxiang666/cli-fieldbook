Manage database tags

Usage:
  coolify database tag [command]

Aliases:
  tag, tags

Available Commands:
  add         Add a database tag
  list        List database tags
  remove      Remove a database tag

Flags:
  -h, --help   help for tag

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify database tag [command] --help" for more information about a command.
