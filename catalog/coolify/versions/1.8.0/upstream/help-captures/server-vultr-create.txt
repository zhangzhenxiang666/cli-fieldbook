Create a Vultr server

Usage:
  coolify server vultr create [flags]

Flags:
      --cloud-init string     Cloud-init YAML
      --cloud-token string    Cloud provider token UUID
      --disable-public-ipv4   Disable public IPv4
      --enable-ipv6           Enable public IPv6 (default true)
  -h, --help                  help for create
      --name string           Server name
      --os-id int             Vultr operating system ID
      --plan string           Vultr plan
      --private-key string    Coolify private key UUID
      --region string         Vultr region
      --ssh-key-ids strings   Additional Vultr SSH key IDs
      --validate              Validate after creation

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
