Server-level shared envs

Usage:
  coolify shared-env server [command]

Available Commands:
  create      Create server shared env
  delete      Delete server shared env
  list        List server shared envs
  update      Update server shared env

Flags:
  -h, --help   help for server

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify shared-env server [command] --help" for more information about a command.
