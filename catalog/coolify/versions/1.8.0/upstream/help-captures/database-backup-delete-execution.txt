Delete a specific backup execution and optionally from S3. First UUID is the database, second is the backup configuration, third is the specific execution.

Usage:
  coolify database backup delete-execution <database_uuid> <backup_uuid> <execution_uuid> [flags]

Flags:
      --delete-s3   Delete backup file from S3
  -h, --help        help for delete-execution

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
