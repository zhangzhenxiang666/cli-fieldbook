Delete a persistent volume or file storage from a database.

Examples:
  coolify db storage delete <db_uuid> <storage_uuid>

Usage:
  coolify database storage delete <db_uuid> <storage_uuid> [flags]

Flags:
  -h, --help   help for delete

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
