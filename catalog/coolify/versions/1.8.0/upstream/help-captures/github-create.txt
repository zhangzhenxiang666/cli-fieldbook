Create a new GitHub App integration. This allows you to deploy private repositories from GitHub.

Required flags: --name, --html-url, --app-id, --installation-id, --client-id, --client-secret, --private-key-uuid

Example: coolify github create --name "My GitHub App" --html-url "https://github.com" --app-id 123456 --installation-id 789012 --client-id "Iv1.abc123" --client-secret "secret123" --private-key-uuid "abc-123-def-456"

Usage:
  coolify github create [flags]

Flags:
      --api-url string            GitHub API URL (derived from --html-url when omitted)
      --app-id int                GitHub App ID (required)
      --client-id string          GitHub OAuth Client ID (required)
      --client-secret string      GitHub OAuth Client Secret (required)
      --custom-port int           Custom port for SSH (default: 22)
      --custom-user string        Custom user for SSH (default: git)
  -h, --help                      help for create
      --html-url string           GitHub HTML URL (required, e.g., https://github.com)
      --installation-id int       GitHub Installation ID (required)
      --name string               GitHub App name (required)
      --organization string       GitHub organization
      --private-key-uuid string   UUID of existing private key (required)
      --system-wide               Is this app system-wide (cloud only)
      --webhook-secret string     GitHub Webhook Secret

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
