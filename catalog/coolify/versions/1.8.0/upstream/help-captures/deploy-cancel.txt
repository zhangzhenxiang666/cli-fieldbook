Cancel an in-progress deployment. This will stop the deployment process and clean up any temporary resources.

Usage:
  coolify deploy cancel <uuid> [flags]

Flags:
  -f, --force   Skip confirmation prompt
  -h, --help    help for cancel

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
