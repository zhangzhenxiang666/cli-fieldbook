Manage Coolify contexts. A context contains the configuration (URL and token) for connecting to Coolify.

Usage:
  coolify context [command]

Available Commands:
  add         Add a new context
  delete      Delete a context
  get         Get details of a specific context
  list        List all configured contexts
  set-default Set a context as the default
  set-token   Update the API token for a context
  update      Update a context's properties (name, URL, token)
  use         Switch to a different context (set as default)
  verify      Verify current context connection and authentication
  version     Get current context's Coolify version

Flags:
  -h, --help   help for context

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify context [command] --help" for more information about a command.
