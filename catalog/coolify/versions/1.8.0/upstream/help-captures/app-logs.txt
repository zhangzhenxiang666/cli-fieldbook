Retrieve logs for an application. Use --follow to continuously stream new logs.

For Docker Compose applications with multiple services, pass --service <name>
(the compose service key, e.g. web or db) to select which container's logs to return.
Without --service, the API returns logs from the first running container.

Usage:
  coolify app logs <uuid> [flags]

Flags:
  -f, --follow            Follow log output (like tail -f)
  -h, --help              help for logs
  -n, --lines int         Number of log lines to retrieve (default 100)
      --service string    Docker Compose service name (selects one container in multi-service apps)
      --show-timestamps   Show timestamps in log output

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
