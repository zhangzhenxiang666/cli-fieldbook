Manage a server's Docker network destinations

Usage:
  coolify server destinations [command]

Available Commands:
  create      Create a server destination
  list        List server destinations

Flags:
  -h, --help   help for destinations

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server destinations [command] --help" for more information about a command.
