Start or redeploy a database in a service

Usage:
  coolify service database start <service-uuid> <database-uuid> [flags]

Flags:
      --force    Rebuild the database container
  -h, --help     help for start
      --latest   Pull the latest image

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
