Verify that the current context is properly configured by testing the connection
to the Coolify instance and validating the API token.

Usage:
  coolify context verify [flags]

Flags:
  -h, --help   help for verify

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
