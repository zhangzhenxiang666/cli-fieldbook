Project-level shared envs

Usage:
  coolify shared-env project [command]

Available Commands:
  create      Create project shared env
  delete      Delete project shared env
  list        List project shared envs
  update      Update project shared env

Flags:
  -h, --help   help for project

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify shared-env project [command] --help" for more information about a command.
