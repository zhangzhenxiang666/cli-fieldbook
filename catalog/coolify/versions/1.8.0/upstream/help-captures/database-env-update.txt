Update an existing environment variable. Identify it by UUID or key name.

Usage:
  coolify database env update <database_uuid> <env_uuid_or_key> [flags]

Flags:
      --comment string   Comment for the environment variable
  -h, --help             help for update
      --is-literal       Treat value as literal
      --is-multiline     Value is multiline
      --is-shown-once    Only show value once
      --key string       New environment variable key (rename)
      --value string     New environment variable value (required)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
