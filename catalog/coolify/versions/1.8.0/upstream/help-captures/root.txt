A CLI tool to interact with Coolify API.
Version: 1.8.0

Usage:
  coolify [command]

Available Commands:
  app          Application related commands
  cloud-init   Manage cloud-init scripts
  cloud-token  Manage cloud provider API tokens
  completion   Output shell completion code for the specified shell
  config       Show configuration file location
  context      Manage Coolify contexts
  database     Manage Coolify databases
  deploy       Deploy related commands
  destination  Manage Docker network destinations
  github       Manage GitHub App integrations
  gitlab       Manage GitLab App integrations
  help         Help about any command
  mcp          Manage the Coolify MCP server
  notification Manage team notification channel settings
  private-key  Private key related commands
  project      Project related commands
  resource     Resource related commands
  s3           Manage S3-compatible storage destinations
  server       Server related commands
  service      Service related commands
  settings     Manage instance settings
  shared-env   Manage hierarchical shared environment variables
  tag          Manage resource tags
  teams        Team related commands
  update       Update Coolify CLI
  version      Current Coolify CLI version

Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -h, --help             help for coolify
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify [command] --help" for more information about a command.
