Manage Coolify teams - list all teams, get team details, view current team, and manage team members.

Usage:
  coolify teams [command]

Aliases:
  teams, team

Available Commands:
  current     Get the team bound to the API token
  get         Get team details by ID
  list        List all teams
  members     Manage team members

Flags:
  -h, --help   help for teams

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify teams [command] --help" for more information about a command.
