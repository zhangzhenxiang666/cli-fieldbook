Create a cloud provider token

Usage:
  coolify cloud-token create [flags]

Flags:
  -h, --help                    help for create
      --name string             Friendly token name
      --provider string         Cloud provider: hetzner, digitalocean, or vultr
      --provider-token string   Provider API token (sensitive; never included in output)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
