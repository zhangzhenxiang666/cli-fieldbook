Manage GitLab App (OAuth) sources for private repository deployments.

Usage:
  coolify gitlab [command]

Aliases:
  gitlab, gl, gitlab-app, gitlab-apps

Available Commands:
  create      Create a GitLab App integration
  delete      Delete a GitLab App integration
  get         Get GitLab App details by ID or UUID
  list        List all GitLab App integrations
  update      Update a GitLab App integration

Flags:
  -h, --help   help for gitlab

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify gitlab [command] --help" for more information about a command.
