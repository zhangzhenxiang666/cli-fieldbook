List all executions for a backup configuration. First UUID is the database, second is the specific backup configuration.

Usage:
  coolify database backup executions <database_uuid> <backup_uuid> [flags]

Flags:
  -h, --help   help for executions

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
