Delete a project by UUID. The project must be empty (no environments with resources).

Examples:
  coolify project delete <uuid>
  coolify project delete <uuid> --force

Usage:
  coolify project delete <uuid> [flags]

Flags:
  -f, --force   Skip confirmation prompt
  -h, --help    help for delete

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
