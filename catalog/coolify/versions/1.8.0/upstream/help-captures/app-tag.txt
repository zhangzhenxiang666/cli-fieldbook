Manage application tags

Usage:
  coolify app tag [command]

Aliases:
  tag, tags

Available Commands:
  add         Add an application tag
  list        List application tags
  remove      Remove an application tag

Flags:
  -h, --help   help for tag

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app tag [command] --help" for more information about a command.
