Sync environment variables from a .env file. This command intelligently:
- Updates existing environment variables with new values
- Creates new environment variables that don't exist yet
- Uses efficient bulk operations where possible

Example: coolify service env sync abc123 --file .env.production

Usage:
  coolify service env sync <service_uuid> [flags]

Flags:
      --build-time    Make all variables available at build time (default: true) (default true)
  -f, --file string   Path to .env file (required)
  -h, --help          help for sync
      --is-literal    Treat all values as literal (don't interpolate variables)
      --runtime       Make all variables available at runtime (default: true) (default true)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
