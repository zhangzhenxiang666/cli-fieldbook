Manage Docker network destinations

Usage:
  coolify destination [command]

Aliases:
  destination, destinations

Available Commands:
  create      Create a destination for a server
  delete      Delete an unused destination
  get         Get a destination
  list        List destinations
  update      Rename a destination

Flags:
  -h, --help   help for destination

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify destination [command] --help" for more information about a command.
