Delete a backup configuration and optionally all its executions from S3. First UUID is the database, second is the specific backup configuration.

Usage:
  coolify database backup delete <database_uuid> <backup_uuid> [flags]

Flags:
      --delete-s3   Delete backup files from S3
  -h, --help        help for delete

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
