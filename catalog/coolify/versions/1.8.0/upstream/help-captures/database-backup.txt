Manage database backups

Usage:
  coolify database backup [command]

Available Commands:
  create           Create a new scheduled backup configuration
  delete           Delete backup configuration
  delete-execution Delete backup execution
  executions       List backup executions
  list             List all backup configurations for a database
  trigger          Trigger immediate backup
  update           Update backup configuration

Flags:
  -h, --help   help for backup

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify database backup [command] --help" for more information about a command.
