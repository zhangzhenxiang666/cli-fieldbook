Manage Coolify projects and their environments.

Usage:
  coolify project [command]

Aliases:
  project, projects

Available Commands:
  create             Create a new project
  delete             Delete a project
  environments       Manage project environments
  get                Get a project by uuid
  list               List all projects
  update             Update a project
  update-environment Update a project environment name or description

Flags:
  -h, --help   help for project

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify project [command] --help" for more information about a command.
