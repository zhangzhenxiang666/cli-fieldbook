List all branches for a specific repository. Provide the app UUID and repository in owner/repo format.

Example: coolify github branches abc-123-def owner/repository

Usage:
  coolify github branches <app_uuid> <owner/repo> [flags]

Flags:
  -h, --help   help for branches

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
