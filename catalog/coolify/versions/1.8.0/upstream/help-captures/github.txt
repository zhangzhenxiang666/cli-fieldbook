Manage GitHub App integrations for private repository deployments.

Usage:
  coolify github [command]

Aliases:
  github, gh, github-app, github-apps

Available Commands:
  branches    List branches for a repository
  create      Create a GitHub App integration
  delete      Delete a GitHub App integration
  get         Get GitHub App details by UUID
  list        List all GitHub App integrations
  repos       List repositories accessible by a GitHub App
  update      Update a GitHub App integration

Flags:
  -h, --help   help for github

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify github [command] --help" for more information about a command.
