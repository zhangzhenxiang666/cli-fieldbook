Manage deployments for a specific application. List deployments or view deployment logs.

Usage:
  coolify app deployments [command]

Available Commands:
  list        List all deployments for an application
  logs        Get deployment logs for an application

Flags:
  -h, --help   help for deployments

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify app deployments [command] --help" for more information about a command.
