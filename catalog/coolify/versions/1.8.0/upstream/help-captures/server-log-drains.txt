Manage server log drain settings

Usage:
  coolify server log-drains [command]

Available Commands:
  get         Get log drain settings
  update      Update log drain settings via JSON

Flags:
  -h, --help   help for log-drains

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server log-drains [command] --help" for more information about a command.
