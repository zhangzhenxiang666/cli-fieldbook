List all resources (applications, services, databases) in Coolify.

Usage:
  coolify resource [command]

Aliases:
  resource, resources

Available Commands:
  list        List all resources

Flags:
  -h, --help   help for resource

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify resource [command] --help" for more information about a command.
