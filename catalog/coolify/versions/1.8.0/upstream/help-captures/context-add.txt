Add a new context

Usage:
  coolify context add <context_name> <url> <token> [flags]

Examples:
context add myserver https://coolify.example.com your-api-token

Flags:
  -d, --default   Set as default context
  -f, --force     Force overwrite if context already exists
  -h, --help      help for add

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
