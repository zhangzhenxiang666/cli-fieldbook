List, create, update, delete, and execute scheduled tasks for services.

Usage:
  coolify service task [command]

Aliases:
  task, tasks, scheduled-task, scheduled-tasks

Available Commands:
  create      Create a scheduled task for a service
  delete      Delete a service scheduled task
  execute     Execute a service scheduled task now
  executions  List executions for a service scheduled task
  list        List scheduled tasks for a service
  update      Update a service scheduled task

Flags:
  -h, --help   help for task

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service task [command] --help" for more information about a command.
