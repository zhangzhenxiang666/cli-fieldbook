Manage service tags

Usage:
  coolify service tag [command]

Aliases:
  tag, tags

Available Commands:
  add         Add a service tag
  list        List service tags
  remove      Remove a service tag

Flags:
  -h, --help   help for tag

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service tag [command] --help" for more information about a command.
