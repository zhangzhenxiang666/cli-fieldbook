Manage SSH private keys for server authentication - list, get, add, update, and remove keys.

Usage:
  coolify private-key [command]

Aliases:
  private-key, private-keys, key, keys

Available Commands:
  add         Add a private key
  get         Get a private key by UUID
  list        List all private keys
  remove      Remove a private key
  update      Update a private key

Flags:
  -h, --help   help for private-key

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify private-key [command] --help" for more information about a command.
