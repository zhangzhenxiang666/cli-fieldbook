Save raw proxy configuration

Usage:
  coolify server proxy set-config <server_uuid> [flags]

Flags:
      --configuration string        Raw proxy configuration
      --configuration-file string   Read configuration from file
  -h, --help                        help for set-config

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
