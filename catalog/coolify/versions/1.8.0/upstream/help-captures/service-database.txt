Manage databases within a service

Usage:
  coolify service database [command]

Aliases:
  database, databases, db, dbs

Available Commands:
  get         Get a database in a service
  list        List databases in a service
  logs        Get logs for a database in a service
  restart     Restart a database in a service
  start       Start or redeploy a database in a service
  stop        Stop a database in a service
  update      Update a database in a service

Flags:
  -h, --help   help for database

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify service database [command] --help" for more information about a command.
