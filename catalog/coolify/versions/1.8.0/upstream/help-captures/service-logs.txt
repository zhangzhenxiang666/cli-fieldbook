Get logs for a service sub-resource

Usage:
  coolify service logs <uuid> [flags]

Flags:
  -h, --help                      help for logs
  -n, --lines int                 Number of log lines to retrieve (default 100)
      --show-timestamps           Include timestamps in logs
      --sub-service-name string   Sub-service name from the service applications or databases list (required)

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)
