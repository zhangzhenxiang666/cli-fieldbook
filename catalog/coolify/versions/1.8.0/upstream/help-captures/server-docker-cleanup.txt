Manage server Docker cleanup settings

Usage:
  coolify server docker-cleanup [command]

Available Commands:
  executions  List docker cleanup executions
  get         Get docker cleanup settings
  run         Run docker cleanup now
  update      Update docker cleanup settings

Flags:
  -h, --help   help for docker-cleanup

Global Flags:
      --context string   Use specific context by name
      --debug            Debug mode
      --format string    Format output (table|json|pretty) (default "table")
  -s, --show-sensitive   Show sensitive information
      --token string     Token for authentication (override context token)

Use "coolify server docker-cleanup [command] --help" for more information about a command.
