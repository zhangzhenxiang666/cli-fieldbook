**适用场景：** 两类需求：临时运行某个 Python 提供的命令行工具（不想安装），或把工具长期安装到机器上供 shell 和其他程序使用。最后处理可执行目录与 `PATH` 的关系。

## 前提

- 已安装 uv 0.12.22，可联网。下文以 `ruff` 为例，替换成你要的工具包名。
- 区分两种接口：[uvx](cli:command:tool/uvx)（即 [uv tool run](cli:command:tool/run)，二者完全等价）执行而不安装；[uv tool install](cli:command:tool/install) 安装后可执行文件进入 `PATH`。

## 步骤

### 1. 临时运行：uvx

```sh
uvx ruff --version          # 首次调用使用最新可用版本，之后复用缓存版本
uvx ruff@0.6.0 --version    # 请求精确版本
uvx ruff@latest --version   # 请求最新版本并刷新缓存
```

`uvx` 的环境放在 uv 缓存目录里，视为一次性资产：`uv cache clean` 会删掉它，下次调用自动重建。版本语义（依据官方文档）：首次调用取最新可用版本；此后使用缓存版本，除非请求了不同版本、缓存被修剪或刷新；`--isolated` 忽略已安装版本且不刷新缓存。附带额外包用 `--with <package>`。不带命令调用 `uvx` 时列出已安装的工具。工具始终与项目隔离运行——接近 `uv run --no-project --with <name> -- <name>`，因此需要项目依赖的工具（如 pytest、mypy 对本项目的测试）应改用 `uv run`。

### 2. 安装

```sh
uv tool install ruff
uv tool install ruff==0.5.0
```

安装到隔离的工具环境（Unix 位于 `$HOME/.local/share/uv/tools`，Windows 位于 `%APPDATA%\uv\data\tools`），可执行文件在 Unix 以符号链接、在 Windows 以复制方式进入可执行目录（用 `uv tool dir --bin` 查看）。依赖包提供的可执行文件不会被安装。之前安装过则一般会被替换。

有依据的失败恢复：若可执行目录中已存在**非 uv 安装**的同名可执行文件（例如先前用 pipx 装过），安装会失败；确认后用 `--force` 覆盖，不要盲目重试。

### 3. PATH 与 update-shell

```sh
uv tool update-shell
```

可执行目录必须在 `PATH` 中，否则工具安装后 shell 找不到命令（uv 会给出警告）。[uv tool update-shell](cli:command:tool/update-shell)（别名 `ensurepath`）会把它追加到常见 shell 配置文件；修改对**新开**的 shell 生效。若配置文件中已有相应片段但目录不在 `PATH` 上，命令会报错——此时应核对配置与 `PATH` 的实际状态，而不是重复写入。

### 4. 升级、清点与卸载

```sh
uv tool list --outdated
uv tool upgrade ruff
uv tool upgrade ruff --upgrade-package click
uv tool uninstall ruff
```

[uv tool upgrade](cli:command:tool/upgrade) 尊重安装时的版本约束与设置（如 `uv tool install "black>=23,<24"` 之后的升级不会越过上界）；要突破约束，用 `uv tool install` 重新安装。升级会重装可执行文件（即使未变化）。[uv tool list](cli:command:tool/list) 支持 `--outdated`（只列过时工具）、`--show-paths` 等查看选项；[uv tool uninstall](cli:command:tool/uninstall) 卸载并移除环境。

安装之后，`uvx ruff` 默认改用已安装版本；`uvx ruff@latest` 或 `--isolated` 可忽略它。

**风险与边界：** 工具环境不应手动改动（例如用 pip 向其中装包）；卸载工具所用的 Python 版本会使工具环境损坏、工具不可用。工具环境绑定特定 Python 版本，忽略 `.python-version` 与 `requires-python`，需要指定时用 `--python`。

**未实测声明：** 本工作流依据 uv 0.12.22 固定提交的源码与官方文档快照编写，命令组合未在真实环境实测；`ruff` 等包名与版本号请替换为实际值。
