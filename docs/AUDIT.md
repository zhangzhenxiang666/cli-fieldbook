## 工程与发布验收

本地和 CI 执行内容只读检查、TypeScript 检查、协议行为测试、完整构建与 Chromium 桌面／手机浏览器测试。协议测试覆盖重复键、危险 Markdown、任意工具发现、根与真实 index 命令、别名、草稿隔离、字段覆盖、越界／符号链接和正文／事实／来源／依赖导致的复核失效。构建后检查全部页面的项目路径、内部链接、资源和锚点；浏览器检查中文及标识搜索、范围切换、键盘关闭、合订下载与窄屏溢出。

每次运行生成 `.generated/manifest.json`、站点审查结果和产物文件摘要；审阅使用本次运行结果，报告不替代 CI 结果。合订 Markdown 与网页调用同一内容渲染函数，并使用明确版本的永久链接。

PR 任务仅持有读取权限。main 先完成检查和构建，再等待 required reviewer；允许单维护者确认自己的部署，关闭管理员绕过，只允许 main 进入发布环境。批准后校验同次运行的产物，添加外部批准记录并部署，不重新安装依赖或生成正文。`review.lock` 只能是 prepared，作者不能通过填写 reviewed 自证批准。

公网地址、实际 Pages 发布和公网浏览器验收仅在维护者批准后确认。批准前的构建通过表示候选产物可审阅，不表示站点已经发布。
